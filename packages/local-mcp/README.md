# xgoose local MCP (Firefox development preview)

Install dependencies from the repository root with `npm ci`. Build and temporarily load `apps/firefox/dist/manifest.json` in Firefox `about:debugging`.

In extension settings, expand Advanced, enable Local MCP control and save. Expand Codex configuration, fill in the absolute path to this directory's `index.mjs`, and copy the configuration to your Codex MCP settings. The default port is 8765; use the same port in both settings. Restart the Codex MCP connection after changing its configuration.

Codex launches the stdio adapter automatically. Adapters share a loopback broker and one Firefox profile per port. The broker exits after 60 seconds with no MCP clients. The extension reconnects when Codex starts it again.

Start one `start_session` per agent/task. Pass that session ID to every browser operation, across all tabs. Call `list_tabs` first to reuse matching open pages. Use `navigate_tab` to reuse a tab at another URL, `open_tab` for a new page, and `close_tab` to clean up temporary task pages. Discover documents with `list_tabs` / `open_tab` and schemas with `list_page_tools`; invoke them with `call_page_tool`. End with `end_session`. The page panel stays closed and new tabs open in the background.

Each session appears once under MCP sessions in extension history. Signed-in tool requests, results and errors upload as external transcripts; anonymous records remain local. No model reasoning is generated by this package. Existing page permissions still apply, including Allow User Scripts for js_exec. Interrupted or unknown operations are not automatically replayed.

This package is local development code, not a published npm package or browser release.
