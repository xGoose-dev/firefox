xgoose 0.3.1 for Firefox brings the current AI research assistant, 34 built-in
website skills, images, source links, local history and context compaction to
Firefox 153+. Built-in skills work without optional script access. Community
scripts and custom actions use Firefox's optional User Scripts permission.

Getting started supports Hosted AI and account-free BYOK, reports connection
readiness and trial eligibility, keeps custom scripts optional, and explains how
to start on the correct website. Sign-in errors can be retried. English, Chinese
and Spanish UI are included. Analytics is off by default and additionally gated
by Firefox's optional data permission.
