Built-in skills and page reading work immediately. To run community skills, edited scripts and custom actions, enable the optional User Scripts permission.

  1. Click Enable User Scripts below.
  2. Approve the permission in Firefox’s prompt.
  3. Return to your website and retry your request.

Checking permission…

You can revoke this permission in Firefox’s Add-ons Manager at any time. Enable scripts only when you trust their source.
